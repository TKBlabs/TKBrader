# TKBrader

macOS用の雨雲レーダーアプリです。市街地まで読める詳しい地図と日本全体の広域地図を左右に並べ、気象庁の雨雲レーダー（実況と予測）を表示します。台風の進路・予報円、落雷の位置、都道府県境を地図に重ねられるほか、画面上部には現在の天気と1時間ごと・日ごとの天気予報をまとめて表示します。「近くの雨がいつ来るか」と「全体の流れ」を1画面で同時に追えます。

- **ダウンロード**: [Releases](https://github.com/TKBlabs/TKBrader/releases)（最新版のDMG）
- **製品ページ**: https://apps.tkbtk.com/TKBrader/
- **動作環境**: macOS 26以降、Apple Silicon（Intel Macには対応していません）、インターネット接続
- **ライセンス**: フリーウェア（個人・商用を問わず無料）

## インストール

1. [Releases](https://github.com/TKBlabs/TKBrader/releases)から最新版の `TKBrader_<バージョン>.dmg` をダウンロードします。
2. DMGを開き、`TKBrader.app` を「アプリケーション」フォルダへドラッグします。
3. 「アプリケーション」フォルダから起動します。

アプリとDMGはどちらもAppleの公証（Notarization）を受けています。初回起動時に「インターネットからダウンロードされたアプリケーションです」と確認が出たら「開く」を押してください。現在地を使う場合は、初回に位置情報の利用を許可してください。

> [!IMPORTANT]
> DMGの中やダウンロードフォルダから直接起動すると、自動アップデートがうまく動かないことがあります。必ず「アプリケーション」フォルダへ移してから起動してください。

## アップデート

自動アップデート（Sparkle）に対応しています。

- 24時間ごとに新しい版を確認します（設定の「更新」でオン・オフできます）。
- メニュー「TKBrader」→「アップデートを確認...」、または設定の「更新」の「今すぐ確認」で、すぐに確認することもできます。

各版の変更点は[Releases](https://github.com/TKBlabs/TKBrader/releases)に載っています。

## 画面構成

画面は上から「天気予報」「雨雲レーダー（左：詳しい地図／右：広域地図）」「出典表記」の順に並びます。各地図の下には、再生モードでは再生バー、ライブモードではライブの帯（シークバー）が出ます。

ツールバー:

| 項目 | 内容 |
| --- | --- |
| 地点名 | 地点の検索・選択と、お気に入りの管理 |
| ライブ／再生 | 表示モードの切り替え |
| 現在地 | 現在地の雨雲と天気を表示（位置情報の許可を求めます） |
| 優先設定 | 設定をその場で開く（設定画面と同じ「一般」の内容） |
| 再描画 | ズームやウィンドウサイズの変更のあと、雨雲や距離の円が消えたままのときに取得し直す |

各地図の左上のボタン:

| ボタン | 内容 |
| --- | --- |
| 範囲 | 距離の目安の円の表示・非表示 |
| 凡例 | 降水強度の凡例を表示 |
| 台風 | 台風の詳細を表示（台風が出ていて、台風の表示がオンのとき） |

## 主な機能

### 雨雲レーダー

- 左右の2画面で、左は市街地まで読める詳しい地図、右は日本全体の広域地図です。2つの地図は常に同じ時刻を表示します。
- **再生**: 過去のコマから順にアニメーションで再生します。シークバーで好きな時刻へ移動できます。
- **ライブ**: 最新の観測を表示し続け、新しいコマが出たら自動で切り替えます。シークバーで先の予測も確認できます（1時間先までは5分刻み、その先は15時間先まで1時間刻み）。
- 遡る範囲は「3時間」（高解像度降水ナウキャスト・5分刻み）と「12時間」（解析雨量／降水短時間予報）から選べます。
- 雨雲を読み込んでいる間や読み込めていないときは、地図上に「雨雲を読み込み中」と表示します。

### 重ねて表示できる情報

- **台風**: 現在位置、進路予想、予報円、暴風警戒域。詳細では名称・階級・存在地域・進行方向と速さ・中心気圧・最大風速・最大瞬間風速を表示します（気象庁の発表を10分ごとに確認）。
- **落雷**: 対地放電の位置（60秒ごとに確認）。
- **都道府県境**: 境界線と県名ラベル。
- **距離の目安**: 選んだ地点を中心にした同心円と距離（km）。

### 天気予報

- 現在の天気（天気・気温・体感気温・露点温度・湿度・風速・風向き・雨量・気圧・日の出／日の入り・日照時間）
- 1時間ごとの予報（天気・気温・降水確率。降水確率が出ないモデルでは1時間の降水量）
- 日ごとの予報（天気・最高／最低気温・降水確率）

取得元は設定の「天気予報」で **Apple WeatherKit**（既定）と **Open-Meteo** から選べます。Open-Meteo では予報モデル（自動、気象庁 MSM／GSM、ECMWF、GFS など）も選べます。Apple WeatherKit から取得できないときは、選んでいる Open-Meteo のモデルで自動的に代わりに表示し、画面下部に橙色でその旨を出します（次の定期取得では再び Apple WeatherKit から試します）。

天気予報は10分ごとに取り直します。ウインドウが見えていない間やスリープ中は取得を控え、見える状態に戻ったときに必要なら取り直します。

### 地点

- 地名・郵便番号で検索して地点を選べます。
- 現在地を地点として使えます（位置情報の許可が必要です）。
- よく使う地点をお気に入りとして保存・削除できます。

## 主なショートカット

| キー | 内容 |
| --- | --- |
| ← / → | 1コマ前／1コマ後へ（再生モードでは一時停止して移動、ライブではシーク） |
| 0・↑・↓ | 最新の観測（現時刻）へ戻る |
| Space | 再生／一時停止 |
| ⌘L | 最新のコマへ |
| ⌘, | 設定を開く |
| ⌘Q | TKBraderを終了 |

検索欄などで文字を入力している間は、← / → / 0 / ↑ / ↓ は文字入力に使われます。

## 設定（⌘,）

| タブ | 項目 | 内容 |
| --- | --- | --- |
| 一般 | 表示 | テーマ（システム／ライト／ダーク）、雨雲の不透明度、天気表示の文字サイズ |
| 一般 | 天気予報 | 取得元（Apple WeatherKit／Open-Meteo）、Open-Meteo の予報モデル |
| 一般 | 再生 | 表示モード、再生速度（コマ/秒）、最終コマで止まる時間、再生の時間刻み |
| 一般 | レーダー | 遡る範囲（3時間／12時間）、予測のコマも再生に含めるか、予測をどこまで表示するか（1〜15時間先） |
| 一般 | 台風 | 台風情報を地図に重ねるか |
| 一般 | 雷 | 落雷（対地放電）を地図に重ねるか |
| 一般 | 都道府県境 | 境界線を重ねるか、県名ラベルを表示するか |
| 更新 | アップデートを自動的に確認 | 24時間ごとの自動確認のオン・オフ |
| 更新 | 最終確認・今すぐ確認 | 最後に確認した日時の表示と、手動での確認 |
| 更新 | このバージョン | 今のバージョンとビルド番号 |

ライブのシークバーは、「予測をどこまで表示するか」にかかわらず、予測のある15時間先まで選べます。

## データの出典

- 気象庁ホームページ（高解像度降水ナウキャスト／解析雨量・降水短時間予報／台風情報／雷ナウキャスト）を加工して作成
- Apple Weather（天気予報の取得元が Apple WeatherKit のとき。画面下部に法的表記へのリンクがあります）
- Open-Meteo.com（CC BY 4.0。天気予報の取得元が Open-Meteo のとき、または代わりに使ったとき）
- 国土地理院 地球地図日本を加工して作成（都道府県境）
- Apple マップ（背景の地図）

予測は気象庁の発表をそのまま表示しており、アプリが独自に雨雲の動きを予測することはありません。避難や防災の判断には、気象庁や自治体が発表する情報を必ずご確認ください。

## 困ったときは

- **雨雲が表示されない・一部だけ四角く欠けたまま戻らない**: ツールバーの「再描画」を押してください。
- **現在地が使えない**: 「システム設定」→「プライバシーとセキュリティ」→「位置情報サービス」で TKBrader を許可してください。
- **画面下部に橙色で「WeatherKitから取得できないため、Open-Meteoの予報を表示中」と出ている**: Apple WeatherKit から取得できず、Open-Meteo で代わりに表示しています。次の定期取得で自動的に再び試します。
- **シークバーの「+2時間」などの時刻がずれて見える**: 1時間より先の予測（降水短時間予報）は観測の時刻と揃わないため、おおよその時間です。正確な時刻はシークバーの右側に表示されます。
- **急に何も表示されなくなった**: 気象庁のデータは公式に案内されたAPIではないため、提供形式が変わった場合は予告なく表示できなくなることがあります。
- **アップデートがうまくいかない**: TKBraderを「アプリケーション」フォルダへ移してから起動し直し、「アップデートを確認...」を試してください。うまくいかなければ、[Releases](https://github.com/TKBlabs/TKBrader/releases)から最新版のDMGをダウンロードして入れ直してください（地点や設定は残ります）。

不具合の調査にログが必要な場合は、ターミナルで次のコマンドを実行すると取得できます。

```sh
/usr/bin/log show --last 1h --predicate 'subsystem == "com.tkbtk.TKBrader"' --style compact
```

## プライバシー

TKBraderが外部と通信するのは、次の用途だけです。

- 雨雲・台風・落雷のデータの取得（`www.jma.go.jp`）
- 天気予報の取得（Apple WeatherKit、または `api.open-meteo.com`。地点の座標を送ります）
- 地図の表示と地点の検索（Apple マップ）
- アップデートの確認（`apps.tkbtk.com` と、更新ファイルのダウンロード先の `github.com`）

地点・検索語・位置情報が開発者へ送られることはありません。お気に入りの地点と設定はこのMacの中だけに保存します。
