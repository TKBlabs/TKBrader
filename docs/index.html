概要

// overview

TKBraderは、気象庁の雨雲レーダーをMacの大きな画面で見るためのアプリです。 市街地まで読める詳しい地図と日本全体の広域地図を左右に並べ、「近くの雨がいつ来るか」と「全体の流れ」を同時に追えます。

雨雲は過去から再生することも、最新の観測を出し続けるライブ表示にすることもできます。 ライブ表示ではシークバーで先の予測に切り替えられ、1時間先までは5分刻み、その先は15時間先まで確認できます。

画面上部には現在の天気と1時間ごと・日ごとの天気予報を並べ、台風の進路と落雷も地図に重ねられます。

主な機能

// features
◫

2画面の雨雲レーダー

左に市街地まで読める詳しい地図、右に日本全体の広域地図。2つの地図は同じ時刻を指したまま動きます。

▶

過去の再生とライブ

過去3時間（最大12時間）の雨雲をアニメーションで再生。ライブでは最新の観測を自動で追い続けます。

⇥

先の予測をシーク

ライブ画面のシークバーで、1時間先までは5分刻み、その先は15時間先まで1時間刻みで予測を確認できます。

☀

天気予報

現在の天気、1時間ごとの予報、日ごとの予報を画面上部にまとめて表示します。取得元は Apple WeatherKit と Open-Meteo から選べます。

◎

台風・落雷

台風の現在位置・進路予想・予報円と、落雷（対地放電）の位置を地図に重ねて表示します。

⌖

地点と距離の目安

地名・郵便番号・現在地から地点を選べます。地点を中心に距離の円を描き、県境・県名も重ねられます。

データについて

// data sources
  • 気象庁 — 高解像度降水ナウキャスト、解析雨量・降水短時間予報、台風情報、雷ナウキャスト。気象庁ホームページのデータを加工して表示しています（地図の縮尺に合わせたタイルの合成など）
  • Apple Weather・Open-Meteo.com — 天気予報（設定で切り替え。Open-Meteo のデータは CC BY 4.0）
  • 国土地理院 地球地図日本 — 都道府県境。線の間引きと変換をして作成しています
  • Apple マップ — 背景の地図

予測は気象庁の発表をそのまま表示しています。アプリが独自に雨雲の動きを予測することはありません。 気象庁のデータの提供形式が変わった場合、予告なく表示できなくなることがあります。 避難や防災の判断には、気象庁や自治体が発表する情報を必ずご確認ください。

# TKBrader

気象庁の雨雲レーダー・予測・台風・落雷と天気予報を1画面にまとめたmacOS用アプリです。

## インストール

  • DMGを開き、TKBrader.app を「アプリケーション」フォルダへドラッグします
  • Appleの公証（Notarization）済みのため、そのままダブルクリックで起動できます
  • 現在地を使う場合は、初回に位置情報の利用を許可してください

## アップデート

  • 24時間ごとに自動で更新を確認し、新しい版があればお知らせします
  • メニュー「TKBrader」→「アップデートを確認...」から手動でも確認できます
  • 自動確認の有無は 設定（⌘,）→ 更新 で切り替えられます

## 動作環境

  • macOS Tahoe 26以降
  • Apple Silicon 搭載Mac（Intel Mac非対応）
  • インターネット接続（雨雲・天気のデータを随時取得します）

## 使い方

  • ツールバーで「再生」と「ライブ」を切り替えます
  • 再生：シークバーで過去から予測までの好きな時刻に移動できます
  • ライブ：シークバーで最新の観測から先の予測に切り替えられます
  • キーボード：← / → で1コマずつ、0・↑・↓ で最新の観測へ戻ります
  • 地点はツールバーの地点名から、地名・郵便番号・現在地で選べます

## 主な機能

  • 詳しい地図と広域地図の2画面レーダー（時刻は常に同期）
  • 過去の再生、ライブ表示、15時間先までの予測
  • 現在の天気、1時間ごと・日ごとの天気予報
  • 台風の進路・予報円、落雷、都道府県境、距離の目安の円

## データの出典

気象庁ホームページ（高解像度降水ナウキャスト／解析雨量・降水短時間予報／台風情報／雷ナウキャスト）を加工して作成
Apple Weather
Open-Meteo.com (CC BY 4.0)
国土地理院 地球地図日本を加工して作成（都道府県境）
